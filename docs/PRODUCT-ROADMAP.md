# Fireworksi — Product roadmap

This roadmap records the intended direction. Items are not considered complete until implemented and tested.

## Phase 0 — Source review and baseline
- [ ] Receive and inspect the original website ZIP.
- [ ] Inventory existing pages, scripts, styles, assets and dependencies.
- [ ] Record current generator behaviour and visual baseline.
- [ ] Check mobile layout, accessibility, performance and broken links.
- [ ] Confirm how the current Netlify site is deployed.
- [ ] Create a safe development preview before production changes.

## Phase 1 — Website foundation
- [ ] Establish consistent, responsive navigation and footer.
- [ ] Improve homepage content and calls to action.
- [ ] Preserve and improve the existing digital fireworks generator.
- [ ] Add About, Contact, Privacy, Terms, Disclaimer and FAQ pages as appropriate.
- [ ] Add accessible loading, error and empty states.
- [ ] Add sitemap, robots rules, canonical URLs and structured data where appropriate.

## Phase 2 — First-visit learning
- [ ] Create a short, skippable first-visit tutorial.
- [ ] Remember completion on the visitor's device.
- [ ] Provide a replay option.
- [ ] Respect reduced-motion preferences and never autoplay audio.

## Phase 3 — Personalised celebrations
- [ ] Build a guided creation flow for occasion, recipient, sender, message and theme.
- [ ] Add preview and replay.
- [ ] Generate unique shareable celebration URLs.
- [ ] Make recipient pages work without account creation.
- [ ] Add privacy controls, data minimisation, validation, expiry/deletion policy and abuse protection.
- [ ] Evaluate Supabase or another suitable backend before implementation.

## Phase 4 — Content and discovery
- [ ] Publish researched fireworks history and science content.
- [ ] Explain health, environmental, animal-welfare and noise impacts.
- [ ] Publish safety guidance based on reputable authorities and applicable local rules.
- [ ] Add event-organiser and spectator guidance without explosive construction instructions.
- [ ] Add fireworks photography and digital-effects tutorials.
- [ ] Add celebration inspiration and useful FAQs.
- [ ] Add a gallery with rights-cleared media and meaningful alt text.

## Phase 5 — Stores, games and partnerships
- [ ] Build a curated Stores directory with verified providers and transparent disclosures.
- [ ] Publish a Games landing page clearly labelled "Coming soon".
- [ ] Add a Resources & Partners area with relevant, reputable external references.
- [ ] Pursue genuine editorial mentions and partnerships; do not buy spam links.

## Phase 6 — Quality, growth and monetisation readiness
- [ ] Test on low-end Android devices and slow connections.
- [ ] Test keyboard, screen-reader and touch accessibility.
- [ ] Measure Core Web Vitals and fix performance bottlenecks.
- [ ] Configure analytics with appropriate privacy disclosures.
- [ ] Review Search Console indexing and query performance.
- [ ] Review AdSense policies and eligibility; approval is not guaranteed.
- [ ] Complete a production QA checklist before release.

## Release rule

Do not deploy unreviewed changes directly to the live site. Preserve the current working version, test changes on a preview, and publish only after the changes pass functional and mobile checks.
